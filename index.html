Apps Script (destino de los PDFs)

🆕 No tengo URL: instalarlo paso a paso

Se hace una única vez, desde el móvil o el ordenador. Sigue los pasos en orden:👇

1📋 Copia el código

Pulsa el botón 📋 Copiar el código. Parece que no hace nada, pero el código se copia solo.

2🆕 Abre Apps Script

Pulsa el botón 🆕 Abrir Apps Script. Se abre en otra pestaña y te pedirá iniciar sesión con tu cuenta de Google.

🆕 Abrir Apps Script
3🗑️ Bórralo y pega el código

Dentro de Apps Script verás un recuadro blanco con este texto azul:

function myFunction() {
  
}

Bórralo primero: pulsa dentro del recuadro → mantén pulsado → Seleccionar todo → Borrar. Luego mantén pulsado otra vez → Pegar. Queda nuestro código; tú no escribes nada.

4🚀 Implementa (4 opciones)

Pulsa el botón azul Implementar (arriba a la derecha) → Nueva implementación. Se abre una ventana que dice "Seleccionar tipo": pulsa el engranaje ⚙️ que hay justo a la derecha.

Elige Aplicación web y comprueba estas 4 opciones:

  • Tipo de implementación → Aplicación web
  • Descripción → pon cualquier texto (por ejemplo, el que sale por defecto "Nueva descripción") — hay que ponerlo sí o sí
  • Ejecutar como → Yo (tu correo) — así los PDFs van a tu Drive
  • Quién tiene acceso → Cualquier persona — obligatorio, si no la web no puede guardar

Pulsa Implementar.

5🔑 Permisos y tu enlace

Si aparece un aviso de permisos ("no verificado", "permitir acceso"…): Opciones avanzadas → Continuar / Acceder a tu proyecto → Permitir.

Copia la URL de la aplicación web (termina en /exec).

⚠️ Guárdala en algún sitio seguro (en tus Notas, por ejemplo): ese enlace es tu conexión permanente y te valdrá para siempre. Si lo pierdes, tendrás que repetir todo el proceso.

Vuelve a esta página y pulsa el botón final ✅ Ya tengo la URL.

Pega el enlace y pulsa 🔗 Probar conexión.

💡¿Dónde se guarda?

Los PDFs se guardan en una carpeta llamada PDFs de Consentimiento, en drive.google.com → Mi unidad. Se crea sola la primera vez que se guarda un PDF; tú no tienes que crear nada.

💡 Puedes abrir la web con ?scriptUrl=TU_URL al final del enlace y la configuración se guardará sola al cargar.

⚠️ La configuración se guarda de forma permanente en el navegador (localStorage), no en ningún servidor. El resto de datos del formulario se borran al recargar la página.

Zona de borrado

Estas acciones borran datos guardados en este navegador. No afectan a tus archivos de Drive.
